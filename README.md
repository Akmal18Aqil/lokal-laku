# Sahabat Legal Figa

Landing page statis untuk Sahabat Legal Figa (sebelumnya Lokal Laku) — Malang dan sekitarnya.

## Deploy ke Vercel

1. Push folder `vercel-lokal-laku` sebagai repository terpisah, atau pilih folder ini sebagai **Root Directory** di Vercel.
2. Framework preset: **Other**.
3. Build command: kosongkan.
4. Output directory: kosongkan.
5. Deploy.

Tidak ada dependency atau environment variable. Halaman siap disajikan langsung dari `index.html`.

## Identitas

- Palet bertema stempel: tinta navy `#1F3A5F` (warna utama), tinta gelap `#1B2A44` (teks), merah cap `#B3362B` (aksen), kayu `#9A6B3F` (gagang, dekoratif), kertas `#F4F1E8`.
- Maskot: Si Cap (`assets/si-cap-sahabat.svg`), stempel bergagang kayu dengan cap SAH.
- Logo: `assets/logo-sahabat-legal-figa.svg` dan versi `-putih` untuk latar gelap.
- Aset yang tidak dipakai lagi: `logo-lokal-laku*.svg`, `si-cap-siap-jual.svg`, `si-figa.svg`.
